# NexEraStore 🛍️
# Next Generation E-Commerce Platform

NexEraStore is a full-stack MERN E-Commerce Web Application built using React.js, Node.js, Express.js, and MongoDB Atlas. The platform provides a modern online shopping experience with secure authentication, email verification, admin dashboard, cart management, Razorpay payment integration, and responsive UI design.

# ⚙️ Installation & Setup

# 1️⃣ Clone Repository
git clone https://github.com/BharatBhushan2608/nexerastore.git

# 2️⃣ Install Dependencies
Frontend
cd frontend
npm install
Backend
cd backend
npm install

# 🔐 Environment Variables

# Backend .env

PORT=8000

MONGO_URI=your_mongodb_uri

SECRET_KEY=your_secret_key

SENDGRID_API_KEY=your_sendgrid_api_key

MAIL_USER=your_verified_email@gmail.com

RAZORPAY_KEY_ID=your_razorpay_key

RAZORPAY_SECRET=your_razorpay_secret

# Frontend .env

VITE_URL=your_backend_url

VITE_RAZORPAY_KEY_ID=your_razorpay_key

# ▶️ Run Project

Frontend
npm run dev
Backend
npm start
